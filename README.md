## 🌟 Overview

**Mechify** is a modern, high-performance automotive assistance and supercar services platform built for Bangladesh and beyond. Designed with an ultra-sleek, dark luxury aesthetic and fluid cinematic animations, Mechify connects drivers with 24/7 emergency roadside support, certified workshop hubs, on-demand fuel delivery, luxury car rentals, and specialized mechanics.

## ✨ Key Features

- **🎬 5-Scene Cinematic Landing Page**: Immersive scroll and mobile-swipe interactive storytelling showcasing luxury vehicles, services, and live animated statistics.
- **📱 Mobile-First Chrome & iOS Optimization**: Responsive layouts, touch-swipe navigation, and dynamic viewport handling (`100dvh`).
- **🚨 24/7 Roadside Emergency Assistance**: Instant SOS dispatch with live response times and emergency mechanics.
- **🛠️ 50+ Verified Dhaka Workshops**: Interactive map and directory with search, live distance calculation, service tags, and instant navigation.
- **⛽ Doorstep Fuel Delivery**: Fuel selection, location setting, and quick delivery request workflows.
- **🏎️ Exotic & Supercar Rental Bay**: Curated fleet showcase featuring McLaren, Lamborghini, Bugatti, Ferrari, and Rolls Royce.
- **🔒 Authentication & User Database**: Persistent accounts, role-based access (Customer vs. Driver), and verification modal flows.

## 🛠️ Tech Stack

- **Frontend:** React 19, React Router v7 (HashRouter for GitHub Pages)
- **Styling:** Tailwind CSS v4, Vanilla CSS animations, Glassmorphism
- **Animations:** GSAP (GreenSock Animation Platform)
- **Interactive Maps:** Leaflet & React-Leaflet
- **Deployment:** GitHub Pages via automated GitHub Actions CI/CD workflow

## 💻 Running Locally (Optional)

If you'd like to inspect or develop the codebase locally:

```bash
# 1. Clone the repository
git clone https://github.com/WillSerfortx/mechify.git

# 2. Navigate to the project directory
cd mechify

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.
